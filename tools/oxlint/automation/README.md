# Automation Oxlint plugin

This directory vendors the runtime source for the `automation` Oxlint plugin from
[typeonce-dev/ai-automation](https://github.com/typeonce-dev/ai-automation), commit
[`0bca096fe6fe9878cd15303a623dd2cd85915ddd`](https://github.com/typeonce-dev/ai-automation/tree/0bca096fe6fe9878cd15303a623dd2cd85915ddd/rules/oxlint/src).

The upstream `config.ts` is an example configuration and is intentionally omitted. The plugin entry point,
catalog, profiles, and complete rule implementation source are vendored unchanged. Update this provenance and
copy the complete runtime source together when refreshing the plugin.
